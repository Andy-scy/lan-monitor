# 数据协议 v1

传输：HTTP（拉）+ WebSocket（推）。编码：UTF-8 JSON。所有数值字段一律**可空（null）**——硬件不支持/获取失败时必须为 `null`，UI 显示「不支持」，绝不伪造。

- 时间戳 `ts` 为 Unix 毫秒（Agent 时钟）。
- 容量单位：**MB（2^20）**；速率单位：**字节/秒**（由手机端格式化为 KB/s·MB/s）；温度 ℃；频率 MHz；功耗 W。
- 多显卡/多磁盘/多网卡一律数组。

字段语义补充：
- `cpu.tempSource`: `thermalZone` | `nvidiaGpu`(无此值时温度来自 GPU 的提示由 UI 处理) | null。
- `cpu.perCore` 长度 = 逻辑核心数；获取失败整体为 null。
- `gpu.usage` = 各引擎利用率最大值（与任务管理器「GPU 利用率」口径一致）；`memTotalMB` 来自 DXGI `DedicatedVideoMemory`。
- `net.downloadBps/uploadBps` = 当前活动网卡聚合；`interfaces` 列出全部有流量的网卡。
- `disks.readBps/writeBps` 按卷名映射自 PhysicalDisk 实例（映射不到时 null）。

## 2. 发现（UDP :42711）

请求负载：`PULSE:DISCOVER:v1`（App 同时发往 255.255.255.255 与网段定向广播）。
应答（单播回源地址，JSON）：

```json
{ "proto": "PULSE:v1", "id": "a1b2c3d4e5f6", "host": "ANDY-PC", "os": "Windows 11",
  "port": 42710, "agent": "1.0.0", "pairingRequired": true }
```

## 3. 鉴权

| 端点 | 方法 | 鉴权 | 说明 |
|---|---|---|---|
| `/api/hello` | GET | 否 | `{name,host,os,port,id,agent,pairingRequired}`；用于手动添加时的连通性探测 |
| `/api/pair` | POST | 否（限速 5/min） | 请求 `{"pin":"123456"}` → 成功 `{"token":"…","name":"ANDY-PC","id":"…"}`，失败 403 |
| `/api/snapshot` | GET | Bearer Token | 单次快照 |
| `/api/ws` | WS | `?token=` | 每 tick 推快照；客户端可发控制帧 |

WS 控制消息（客户端→服务端，文本 JSON）：

```json
{ "ctrl": { "intervalMs": 2000 } }   // 自适应降频，下限 500，上限 10000
```

## 4. 错误语义

- 401：Token 缺失/失效 → App 重新走 PIN 配对。
- 数值 `null` ≠ 0：UI 必须区分「不支持」与「0%」。
- 快照内某域采集失败时该域为 null（如 `"gpus": null`），域内单卡失败则该卡对应字段 null。

## 5. 遥控输入（WS `/api/input?token=`，v1.1 新增）

独立于数据 WS 的低延迟通道。客户端 → 服务端文本 JSON，逐条注入（user32 SendInput，用户态免管理员）：

| t | 字段 | 动作 |
|---|---|---|
| `mv` | dx,dy | 鼠标相对移动 |
| `cl` | b(0左/1右/2中), dbl(1=双击) | 单击 |
| `bd` | b, d(1按下/0抬起) | 按键拖拽 |
| `wh`/`hw` | delta | 垂直/横向滚轮（±120=一格） |
| `tx` | s | Unicode 文本注入（支持中文，逐 UTF-16 码元） |
| `kk` | k | 单键（enter/esc/tab/f1..f12/字母数字等） |
| `cb` | keys[] | 组合键（依序按下逆序抬起，如 ctrl+c） |

Android 端入口：Dashboard「遥控」区 → 触控板手势（单指移动/点按左键/双击/长按拖拽/双指滚动/双指点按右键）+ 文本框（diff 转发）+ 快捷键条。
